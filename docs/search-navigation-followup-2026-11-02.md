# Search navigation and shared focus

RecordResultList section headings use h2 beneath the host page title. A host can
pass one mixed-type group to retain server ranking, or one typed group selected
through its rail. Search-specific navigation and scope semantics stay in the app.

Rail item counts use secondary ink so selected purple surfaces retain readable
contrast. Message editors now carry their own keyboard focus outline, including
compact/docked modes where card focus alone cannot identify the input. Idle
composers fold references into the context menu below 640px of available width,
retaining the subject in the tooltip/menu and restoring full chips when widened.

Tooltips dismiss on activation and ignore focus bubbling from portal menus.
The ScopeHeader overflow action uses a stable transparent border in both themes.

Validation: 1,028 test files, 11,301 passing tests (two existing skips), lint and
distribution build passed. App verification and retained audit work are recorded
in aws-agentcore/docs/work-social-ui-todo.md and its scoped-search report.
